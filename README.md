# 4K Image Enhancer

A simple, privacy-friendly image enhancer that runs entirely in your browser. Upload a photo, upscale it, adjust it, and download the result — no photo is uploaded to a server.

## Features

- Upload by drag & drop or click
- Upscale to 1.5×, 2×, 3×, or 4K (3840px)
- Presets: Balanced, Sharp Pro, Vivid, Soft
- Adjust sharpness, brightness, contrast, saturation, and smoothness
- Before / after comparison slider
- Download as PNG, JPG, or WebP
- Roman Urdu interface

## How to use

1. Open `index.html` in a browser, or serve this folder with any static host.
2. Upload a photo.
3. Choose a size and preset, adjust the sliders if you want.
4. Compare with the before/after slider.
5. Download the enhanced image.

## How it works

This tool uses stepwise upscaling and sharpening in the browser (canvas). It is **not** a paid AI super-resolution service — it improves a photo by upscaling and enhancing it locally, without sending it anywhere.
